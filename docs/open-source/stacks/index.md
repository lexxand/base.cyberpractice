# Готовые open-source стеки

Практические архитектуры из нескольких открытых компонентов, например стек
сетевого мониторинга или небольшая лаборатория анализа событий.

Для каждого стека необходимо описать:

- решаемую задачу и модель угроз;
- схему компонентов и потоки данных;
- минимальные и рекомендуемые ресурсы;
- процедуру развёртывания и обновления;
- хранение секретов и hardening;
- ограничения масштабирования;
- проверенный сценарий демонтажа или восстановления.
