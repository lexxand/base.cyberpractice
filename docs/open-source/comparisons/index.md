# Сравнения открытых решений

Сравнения строятся по заранее опубликованной методике, а не по общему
впечатлению автора. Минимальные критерии:

- покрываемые сценарии;
- архитектура и требования к ресурсам;
- лицензия и ограничения;
- сложность внедрения и сопровождения;
- интеграции и форматы данных;
- активность проекта и качество документации;
- известные ограничения безопасности.

Дата сравнения обязательна: состояние open-source проектов быстро меняется.
