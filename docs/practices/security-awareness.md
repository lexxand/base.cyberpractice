# Повышение осведомлённости

План наполнения:

- целевые аудитории и модели поведения;
- вводное и регулярное обучение;
- обучение для привилегированных и технических ролей;
- симуляции фишинга и этические ограничения;
- каналы сообщения о подозрительных событиях;
- измеримые результаты без наказания пользователей за обучение.
