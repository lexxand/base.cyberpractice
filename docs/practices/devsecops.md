# DevSecOps

План наполнения:

- моделирование угроз и security requirements;
- безопасная разработка и code review;
- SAST, DAST, SCA, IaC и secret scanning;
- защита CI/CD и артефактов;
- SBOM и безопасность цепочки поставок;
- управление уязвимостями приложений;
- метрики, исключения и обратная связь разработчикам.
