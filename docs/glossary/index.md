# Глоссарий

Единая точка входа для терминов, определений и сокращений.

Термин должен содержать:

- русское и английское наименование;
- краткое определение простыми словами;
- более строгое определение со ссылкой на источник;
- контекст применения;
- связанные и часто путаемые термины;
- ссылки на содержательные статьи.

Планируемые указатели: по русскому названию, английскому названию и сокращению.
