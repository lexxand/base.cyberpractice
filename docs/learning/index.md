# Обучение и сертификации

Раздел для учебных маршрутов, лабораторных работ, книг, курсов и профессиональных
сертификаций.

Материалы будут сгруппированы по роли и уровню подготовки. Для сертификации
указываются организация, актуальная версия экзамена, стоимость на дату проверки
и официальная ссылка. Утечки экзаменационных вопросов не публикуются.
