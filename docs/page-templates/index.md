# Шаблоны страниц

Шаблоны поддерживают одинаковую структуру и позволяют сравнивать сущности.

- [Статья базы знаний](knowledge-article.md)
- [Карточка вендора](vendor.md)
- [Карточка продукта](product.md)
- [Карточка open-source проекта](open-source-project.md)

При копировании шаблона замените `example-*` на уникальный стабильный `id`.
Личная отметка о прочтении привязана к этому идентификатору.
