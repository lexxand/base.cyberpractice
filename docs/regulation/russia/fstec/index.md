# Документы ФСТЭК России

Будущий каталог приказов, методических документов, требований к защите
информации, сертификации средств защиты и Банка данных угроз безопасности.

Для сертифицированных продуктов сведения из реестра должны сопровождаться
датой проверки и ссылкой на конкретную запись или официальный документ.
