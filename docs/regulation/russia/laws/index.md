# Федеральные законы

Будущий каталог федеральных законов, связанных с защитой информации,
персональными данными, критической информационной инфраструктурой, электронной
подписью и лицензируемой деятельностью.

Карточка закона должна описывать не только краткое содержание, но и границы
применимости, подзаконные акты и дату последней проверки редакции.
