# Документы ФСБ России

Будущий каталог требований и документов, относящихся к криптографической защите,
электронной подписи, лицензированию и применению СКЗИ.

Необходимо явно отделять общедоступные требования от документов ограниченного
распространения и не воспроизводить материалы, публикация которых неправомерна.
